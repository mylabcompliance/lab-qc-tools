Westgard QC rules calculator

Paste QC results for one or two control levels with their target mean and SD. You get a Levey-Jennings chart and every Westgard rule violation, run by run.

The rules this calculator checks

RuleViolationTypical meaning
1-2sOne result beyond ±2 SDWarning: inspect the other rules
1-3sOne result beyond ±3 SDRandom error
2-2sTwo consecutive results beyond 2 SD on the same side (or both levels in one run)Systematic error
R-4sOne level above +2 SD and the other below -2 SD in the same runRandom error
4-1sFour consecutive results beyond 1 SD on the same sideSystematic error
10xTen consecutive results on the same side of the meanSystematic error (shift)

CLIA requires labs to follow their own QC procedures and to document corrective action before reporting patient results (42 CFR 493.1256 and 493.1282). Your lab director decides which rules apply to each test; this tool checks all of them so you can see the full picture.
